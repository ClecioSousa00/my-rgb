## Destaques

- **Autostart no Linux corrigido.** O Electron não implementa
  `setLoginItemSettings` no Linux — a função é vazia. A opção "Iniciar com o
  sistema" ficava salva, mas nenhuma entrada era criada e o MyRGB não abria no
  login. Agora o programa escreve
  `~/.config/autostart/my-rgb.desktop` (ou `$XDG_CONFIG_HOME/autostart/`)
  com o caminho correto do `.AppImage`, do pacote `.deb` ou do modo de
  desenvolvimento, sempre com `--hidden` para abrir na bandeja.
- Quem já tinha a opção ligada **não precisa mexer em nada**: a entrada é
  recriada no arranque seguinte. Desligar a opção apaga o ficheiro.
- Windows e macOS continuam a usar o registro/login item do sistema, sem
  mudanças de comportamento.
- Documentação alinhada com o código: roteador de iluminação (`LightRouter`),
  campo opcional `targets`, botão **Salvar** (gravar por cima ou criar cópia),
  helper de FPS e sensores do Windows e contagem de testes. Os documentos
  obsoletos `DISCOS.md` e `features.md` foram removidos.

## Se você usa a 0.3.1 no Linux

A opção pode estar marcada sem que exista a entrada de autostart. Duas formas
de resolver:

1. Atualize para esta versão e abra o programa uma vez — a entrada é recriada
   automaticamente.
2. Ou desligue e ligue novamente **⚙ → Iniciar com o sistema**.

Para conferir:

```bash
ls -l ~/.config/autostart/my-rgb.desktop
```

## Notas

- Linux: a regra udev continua a ser instalada pelo `.deb`; é preciso
  desconectar e reconectar o controlador AURA (ou reiniciar) depois de instalar.
- Windows: o instalador continua a incluir o helper de FPS e sensores quando
  ele foi gerado com `npm run build:helper` antes do `build:win`.
- Nada é enviado para servidores: registos e relatórios de crash ficam na
  máquina.
