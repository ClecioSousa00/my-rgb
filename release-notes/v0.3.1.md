## Destaques

- Corrige o pacote **`.deb` que não abria** no Debian/Ubuntu: o `chrome-sandbox`
  volta a ser instalado como setuid (`4755`, root), que é o modo exigido pelo
  Electron quando o sistema restringe *user namespaces* (Ubuntu 24+).
- O `.deb` volta a criar o link **`/usr/bin/my-rgb`**, então o programa também
  abre pelo terminal, não só pelo menu.
- Instala o perfil **AppArmor** do Electron no `.deb`, necessário no Ubuntu 24+.
- A página **Registos** abre o ficheiro atual automaticamente, não mostra mais
  o mesmo selo de nível em todos os ficheiros e mantém os traços de pilha ao
  visualizar e exportar. Cancelar o diálogo de exportação não é mais tratado
  como erro.
- Documentação atualizada: módulo de discos, página de registos, helper do
  Windows (FPS e sensores) e o funcionamento do pacote `.deb`.

## Se você instalou a 0.3.0

A 0.3.0 foi publicada com o `chrome-sandbox` em `0755`. Para abrir sem
reinstalar:

```bash
sudo chmod 4755 /opt/MyRGB/chrome-sandbox
```

Ou instale esta versão, que já corrige o pacote:

```bash
sudo dpkg -i my-rgb_0.3.1_amd64.deb
```

Para conferir:

```bash
stat -c '%a %U' /opt/MyRGB/chrome-sandbox   # 4755 root
readlink -f /usr/bin/my-rgb                 # /opt/MyRGB/my-rgb
```

## Notas

- Linux: a regra udev continua a ser instalada pelo `.deb`; é preciso
  desconectar e reconectar o controlador AURA (ou reiniciar) depois de instalar.
- Windows: o instalador continua a incluir o helper de FPS e sensores quando
  ele foi gerado com `npm run build:helper` antes do `build:win`.
- Nada é enviado para servidores: registos e relatórios de crash ficam na
  máquina.
